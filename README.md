## ✨ Recursos

- 🔒 **Segurança em primeiro lugar** — bloqueio de acesso direto, escape de saídas, remoção de versões
- ⚡ **Otimizado** — carregamento de assets organizado, controle de versão, `defer`/`async`
- ♿ **Acessível** — navegação por teclado, ARIA, leitores de tela
- 📱 **Totalmente responsivo** — layout adaptado a celulares, tablets e desktops
- 🎨 **Pronto para blocos** — suporte nativo ao Editor Gutenberg
- 🔤 **Traduzível** — strings preparadas para internacionalização
- 🧩 **Reutilizável** — arquitetura com `template-parts`
- 📐 **Padrões oficiais** — segue a hierarquia de templates do WordPress
